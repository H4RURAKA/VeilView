VeilView 빠른 시작
==================

1. BUILD_SINGLE_EXE.cmd 실행
2. 빌드 성공 후 dist\VeilView.exe 실행
3. 키보드 입력을 유지하고 싶은 창을 먼저 클릭
4. VeilView에서 웹페이지를 마우스로 조작
5. 글자 입력이 필요하면 [주소 입력] 클릭
6. 제스처를 바꾸려면 [제스처] 클릭

마우스 제스처 기본값
---------------------
←  이전 페이지
→  다음 페이지
↕  새로고침
┌  왼쪽 탭 이동
┐  오른쪽 탭 이동
┘  탭 닫기
└  동작 없음

배포 파일
---------
dist\VeilView.exe 하나만 배포해도 됩니다.
단, 실행 PC에 Microsoft Edge WebView2 Runtime이 필요합니다.
