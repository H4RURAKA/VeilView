VeilView 빠른 시작
===================

[빌드]
1. 이 폴더에서 BUILD_SINGLE_EXE.cmd를 실행합니다.
2. 빌드가 끝나면 dist\VeilView.exe가 생성됩니다.
3. dist\VeilView.exe는 파일 하나만 다른 위치로 옮겨 실행할 수 있습니다.

[실행]
1. 키보드 입력을 유지하고 싶은 창을 먼저 클릭합니다.
2. VeilView.exe를 실행합니다.
3. 키보드 보존 상태에서 웹페이지를 마우스로 클릭하거나 스크롤합니다.
4. 글자를 입력해야 할 때는 주소 입력 버튼을 누릅니다.
5. 입력이 끝나면 보존 복귀를 누릅니다.

[투명도]
- 0%: 투명도 없음
- 30%: 중간 투명도
- 70%: 높은 투명도

[탭]
- + 버튼: 새 탭
- × 버튼: 현재 탭 닫기
- 웹페이지의 새 탭/새 창 요청은 VeilView 내부 탭으로 열립니다.

[주의]
- 실행 PC에 Microsoft Edge WebView2 Runtime이 필요합니다.
- 대부분의 Windows 10/11에는 이미 설치되어 있습니다.
- 오류가 나면 REPAIR_WEBVIEW2_RUNTIME.cmd를 실행하세요.
