VeilView 빠른 시작

1. BUILD_SINGLE_EXE.cmd 실행
2. dist\VeilView.exe 실행
3. 작업할 창을 먼저 클릭해 키보드 포커스를 잡기
4. VeilView에서 웹페이지 클릭/스크롤
5. 글자 입력이 필요하면 [직접 입력] 클릭
6. 입력 후 Enter, [이동], 또는 [작업창 복귀] 클릭

기본 제스처
←  이전 페이지
→  다음 페이지
↕  새로고침
↔  직접 입력 / 작업창 복귀 전환
┌  오른쪽 탭 이동
┐  왼쪽 탭 이동
┘  탭 닫기
└  탭 닫기

불투명도
- [불투명도] 버튼 클릭
- 슬라이더에서 100%~30% 설정
- 100%는 완전 불투명, 30%는 많이 투명
